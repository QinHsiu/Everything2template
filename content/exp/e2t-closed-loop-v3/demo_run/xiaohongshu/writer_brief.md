## Platform template
# 小红书模板 / Xiaohongshu

## 目标

信息流可停滑的图文笔记：短、具体、可跟做。正文通常 200–700 字。

## 结构（必须）

```text
标题行（≤20 字，关键词前置，可 1 个 emoji）

先说结论 / 结果（1–2 行）

1️⃣ 要点一（一行一事）
补充半行细节

2️⃣ 要点二
…

避坑 / 对比（可选）

互动问句 + 话题标签 #标签1 #标签2 #标签3
```

## 标题公式

- 关键词开头（人群/场景/效果）+ 情绪或结果
- 例：`学生党省钱｜这 3 个工具真的够用`
- 避免夸张违禁：最牛、第一、100% 有效（除非源文可证）

另给 3 个备选标题（均 ≤20 字）。

## 开头（共鸣 → 价值 → 往下看）

先用 1–2 行打共鸣（痛点/场景），再说「这篇能带走什么」，再进入清单。目标是**可收藏**的步骤感，而不是空喊情绪。

## 文风

- 像朋友安利，不要公文、不要论文腔
- 每段 1–2 行；善用换行呼吸感
- emoji 适量（每 2–4 段 1 个），禁止刷屏
- 数字、步骤、前后对比优先于形容词
- 结尾给一个可收藏动作（保存步骤 / 评论关键词）

## 配图建议（元数据）

- 封面：大字标题 + 干净背景
- 内页：3–6 张（步骤 / 对比 / 截图示意）
- 输出时列出每张图应出现的文字要点

## format vs rewrite

- `format`：压缩长文为清单，保留原信息点
- `rewrite`：重写成种草/教程口吻，可改钩子与顺序，不可编造体验数据
