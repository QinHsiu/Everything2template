# 别再同文换皮了：把任何材料变成可发布内容：我用 

> 摘要：创作者最耗时间的不是「写」，而是「同一件事用三种平台语言再说一遍」。

先说一句得罪人的话：大多数人不是不会写，而是同一份材料要在不同平台「再说一遍」，最后写成了同文换皮。

围绕「把任何材料变成可发布内容：我用 Everything2template 做了一稿三发」，真正费时间的往往是适配，不是灵感。比如：源材料形态太多：网页、PDF、文档、代码、整个项目。

## 问题

先抓重点——「问题」不是口号，是一组能执行的约束：

**源材料形态太多：网页、PDF、文档、代码、整个项目**

输入越杂，越需要先统一成中间表示，再谈改写。

**平台语风差异大，模板套用不等于平台原生**

平台不同，结构就要不同；只改语气是自我安慰。

**导出经常卡在「只能复制文本」，不便存档或对外交付**

交付物要能存档、能发给同事；只活在对话框里的文本不够。

## 方法

先抓重点——「方法」不是口号，是一组能执行的约束：

**先把材料摄入成 CIR（Canonical Intermediate Representation）**

输入越杂，越需要先统一成中间表示，再谈改写。

**再按平台模板重写结构（不是同文换皮）**

平台不同，结构就要不同；只改语气是自我安慰。

**用质量门禁检查套话、长度、CTA**

发出去前先过一遍质量门，比发出去再删更体面。

**导出 Markdown / PDF**

交付物要能存档、能发给同事；只活在对话框里的文本不够。
