# Everything2template

## Any source → 公众号 / 小红书 / 知乎 → MD & PDF

Stop rewriting the same piece three times.

**Ingest** webpages, PDFs, docs, code, or whole projects.  
**Rebuild** native drafts for WeChat, Xiaohongshu, and Zhihu.  
**Export** Markdown and print-ready PDF — local-first, agent-native.

### Who it's for

- Technical creators shipping to 3 platforms
- Agencies adapting client PDFs into social drafts
- Builders turning repos into launch notes

### Not another matrix publisher

We don't take over your accounts. We make the writing step fast and correct.

### Get started

```bash
pip install -e .
e2t run examples/sample_inputs/demo_article.md
```

Cursor: install `skill/everything2template`, then `/e2t <source>`.
