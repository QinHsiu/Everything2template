# Demo script (60–90s)

Record this once for landing / README / social proof.

## Setup

```bash
pip install -e .
e2t run examples/sample_inputs/demo_article.md --out-dir examples/sample_outputs/demo_run --voice tech_builder
```

## Voiceover beats

1. **0–10s** — Problem: one source, three platforms, endless rewrite  
2. **10–25s** — Show ingest: URL / PDF / project (cut 3 flashes)  
3. **25–50s** — Open `cir.json` brief, then polished WeChat / XHS / Zhihu samples side by side  
4. **50–70s** — Show validate + MD/PDF export  
5. **70–90s** — CTA: `pip install` + `/e2t` + Pro waitlist link  

## On-screen checklist

- [ ] Terminal `e2t run` succeeds  
- [ ] Three drafts visible  
- [ ] PDF opens (CJK font present)  
- [ ] End card with GitHub URL
