# Tecience 商业化闭环（微信公众号）

主收款与交付通道：**微信公众号 Tecience**（非 Gumroad 优先）。

## 闭环定义（可自验证）

```text
试用/内容触达 → 关注 Tecience → 关键词回复 → 付费指引 → Pro 交付 → 复购/转介
```

| 环节 | 资产 | 完成标准 |
|------|------|----------|
| 触达 | 公众号成稿 HTML + 试用台 CTA | 文末明确「关注 Tecience」 |
| 转化 | 自动回复文案（关键词） | 用户回复可拿到价目与付款方式 |
| 收款 | 微信收款码 / 赞赏 / 商家转账说明 | `docs/pay_tecience.md` 可执行 |
| 交付 | Pro zip + 安装说明 | `releases/*-pro-*.zip` + 回复交付话术 |
| 留存 | 支持渠道 + 更新承诺 | Pro README / SUPPORT |

## 关键词（建议配置在 Tecience 后台）

| 用户回复 | 机器人回复要点 |
|----------|----------------|
| `E2T` / `模板` / `改写` | 产品一句话 + Hobby 开源链接 + Pro ¥99 付款方式 + 付款后发「已付」 |
| `已付` / `付款截图` | 人工或半自动发 Pro 网盘/邮件链接 + 安装步骤 |
| `试用` | 本地 `e2t web` 说明 + GitHub |

完整话术见 `content/publish/tecience/auto_reply.md`。

## 运营动作（今晚可完成的部分）

1. 打开 `content/publish/tecience/launch_wechat.md` → 导出 HTML → 粘贴进 Tecience 草稿箱发布。
2. 在公众号后台配置关键词自动回复（上表）。
3. 在 `docs/pay_tecience.md` 填入真实收款码路径或说明。
4. 试用台页脚已引导「关注 Tecience 回复 E2T」。

> 无法替你登录微信公众平台；**闭环在产品侧已打通到「可发布 + 可收款指引 + 可交付」**。真实首笔收款取决于你点「发表」与配置菜单。
