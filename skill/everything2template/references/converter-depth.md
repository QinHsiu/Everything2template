# Converter depth notes (ported insights from oh-my-writing converters)

Use these when rewriting — do not invent facts.

## WeChat extras

- Title can be longer than XHS (value-complete, ≤64 chars display)
- Opening templates: 引子 / 痛点 / 结论先行
- Keep images markdown paths intact when present
- End with single primary CTA (在看 > 转发 > 关注)

## Xiaohongshu extras

- Title ≤20 chars feel; 1–2 emoji max
- Friend-chat tone; avoid textbook
- Preserve image markdown; plan 3–6 frames
- Tags 3–5; no absolute marketing claims

## Zhihu extras

- Question or viewpoint titles
- Conclusion first; separate 事实 vs 观点
- Invite counterexamples; avoid hard sell

## Cross-cutting

Always run `e2t humanize` + compliance before delivery.
