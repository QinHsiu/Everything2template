# 微信公众号模板 / WeChat

## 目标

写出适合手机阅读、可直接进编辑器的公众号长文草稿（推荐 1200–2800 字）。

## 结构（必须）

```text
# 主标题（≤30 字，前 15 字抓人）
> 摘要（分享卡片，≤54 字）

开篇钩子 1–2 段（场景 / 冲突 / 反常识）

## 小标题 1
段落（每段 3–5 行）

## 小标题 2
…

## 小结
行动建议 1–3 条

---
互动引导（在看 / 关注）
```

## 标题公式（选一）

1. 数字 + 痛点 + 方法：`3 个方法，解决…`
2. 对比：`A 和 B 的差距，只在这一点`
3. 疑问：`为什么 …？答案有点反直觉`
4. 身份 + 悬念：`做了 N 年 …，我劝你…`

另给 3 个备选标题。

## 开头模板（选一，吸收自一线公众号转换实践）

**引子式：** 场景 / 冲突一句 → 这篇要解决什么 → 进入正文  
**反常识式：** 「很多人以为…，其实…」→ 用源文事实支撑  
**清单预告式：** 「下面只讲 N 件事」→ 降低跳出

## 文风

- 正式但不生硬：比社交平台正式，比论文亲切；有观点、有论据
- 口语书面化：像朋友讲清楚一件事，不是汇报材料
- 短段落；关键句可加粗（Markdown `**`）
- 少用空泛词：赋能、闭环、抓手、底层逻辑（除非源文本身在讲这些）
- 每约 300–500 字暗示一处配图位：`<!-- 配图：... -->`

## 排版提示（给运营）

- 正文字号约 15px，行距 1.75–2
- 封面图建议 900×383
- 文末 CTA：在看 > 转发 > 关注（按目标选一个主 CTA）
- 若为产品向内容：引导关注公众号 **Tecience**，回复 **E2T** 获取 Pro / 付费说明

## format vs rewrite

- `format`：保留原论证顺序，只切段、加小标题、补摘要与 CTA
- `rewrite`：可重排结构，强化钩子与小节行动，但不得新增事实
